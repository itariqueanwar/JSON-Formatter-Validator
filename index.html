Common JSON syntax errors & how to fix them.

JSON is strictly standardized under RFC 8259. Here is how to fix the most frequent syntax mistakes.

1. Trailing Commas

In standard JSON, a comma after the last property or array element causes a parse failure.

❌ Invalid { "id": 1, "active": true, }
✓ Valid { "id": 1, "active": true }

2. Single Quotes Instead of Double Quotes

JSON strings and property keys must strictly use double quotation marks ("), not single quotes (').

❌ Invalid {'status': 'success'}
✓ Valid {"status": "success"}

3. Unquoted Property Names

Unlike regular JavaScript objects where keys can be bare identifiers, all JSON keys must be wrapped in double quotes.

❌ Invalid { username: "alex", age: 28 }
✓ Valid { "username": "alex", "age": 28 }

4. Comments in JSON

Standard JSON does not support inline comments (//) or multi-line comments (/* ... */). Strip comments before parsing.

❌ Invalid { "version": 1 // current }
✓ Valid { "version": 1 }

Frequently asked questions.

Got questions about formatting, privacy, or JSON syntax? Find answers below.

Is this JSON formatter completely free?

Yes. Formatting, validating, repairing, and minifying JSON is 100% free with no account, subscription, or usage limits required.

Does Redsite upload, store, or log my JSON?

No. All JSON processing happens entirely on your local machine using your browser's native JavaScript parser. Your data never leaves your device and is never uploaded to any remote server.

What causes JSON syntax errors and how can I fix them?

Common syntax errors include trailing commas after the last item, single quotes instead of double quotes, unquoted property keys, or comments. You can use our built-in Auto-Fix button to automatically resolve these common issues.

How does the JSON Minifier work?

Minification removes all unnecessary whitespace, indentations, and newlines from your JSON payload while preserving all data. This reduces payload size and bandwidth consumption for web APIs.

Can I format large JSON files?

Yes. Because processing runs locally in your browser's memory, you can format multi-megabyte payloads quickly without being restricted by server upload limits.

What is the difference between JSON and a JavaScript Object?

JSON (JavaScript Object Notation) is a strict text-based data format defined by RFC 8259. In JSON, property names must be enclosed in double quotes, strings must use double quotes, trailing commas are invalid, and comments or functions are disallowed.

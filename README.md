# JSON Formatter & Validator by Redsite

Standalone static site intended for `json.redsite.in` and Cloudflare Pages. Format, validate, and minify JSON locally in the browser. No JSON content is uploaded.

## Development

Run `npm install`, then `npm run dev`. Deploy the generated `dist/` directory to Cloudflare Pages.

## SEO included

Title and description, canonical URL, Open Graph and Twitter metadata, WebApplication and FAQPage JSON-LD, robots.txt, and sitemap.xml. Update the production hostname in these files if it changes.
